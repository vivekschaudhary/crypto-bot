# Playbooks

Stack-specific learnings captured across projects, per AGENTS.md and `compass/templates/playbook.md`.

This directory starts empty on a fresh project. It fills in **lazily** — via `/measure` soft prompts when bets resolve with notable technical learnings, or via `/retro` when a recurring pattern is named across improvements.

**Signal-consultation rule:** new architectural decisions in `/setup-foundation-architecture` and `/create-bet-architecture` consult this directory for prior learnings with matching `stack_combo` tags. "n/a — empty directory" is valid only for first-project bootstrap; once playbooks exist, citing them is mandatory when stack overlap is real.

See `compass/templates/playbook.md` for the artifact shape.
